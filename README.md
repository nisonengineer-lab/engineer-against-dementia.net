# BeKavod — engineeragainstdementia.net

Лендинг проекта домашнего присмотра за пожилыми. Статический сайт,
без сборки и без зависимостей: открывается как есть.

## Что где

```
index.html          лендинг, вся разметка одной страницей
journal/            журнал событий (за входом)
status/             состояние системы: где порвалась цепочка
engineering/        раздел в работе
video/              раздел в работе

css/style.css       дизайн-система и вёрстка лендинга
css/journal.css     журнал
css/fault.css       карточка сбоя и страница состояния

js/i18n.js          выбор языка и подстановка переводов
js/wires.js         прорисовка проводов по скроллу
js/brain.js         живая нейросеть на canvas (блок «Разум»)
js/api.js           запросы к серверу, таймауты, разбор причины сбоя
js/fault.js         показ поломки: что · почему · что делать
js/journal.js       лента, фильтры, вход, оценки, удаление
js/status.js        проверка цепочки звено за звеном

i18n/*.json         тексты: ru · en · he
images/             фотографии, подготовлены детерминированным скриптом
CNAME               домен для GitHub Pages
```

## Журнал и сервер

Журнал — не статика: он ходит за данными к отдельному серверу. Адрес
задаётся одной строкой в `<head>` страниц `journal/` и `status/`:

```html
<meta name="api-base" content="https://api.example.net">
```

Пусто — тот же домен. Подменить на время проверки, не трогая файл:
`?api=<адрес>`. Сервер и сайт должны быть на одном домене или на его
поддомене — иначе не уйдёт кука сессии и не загрузятся кадры.

Страница `status/` проверяет всю цепочку от устройства до сервера и
называет причину обрыва. Набор сценариев аварии для проверки вёрстки —
`status/?dev=1`.

## Языки

Русский лежит прямо в разметке — без JS и без сети страница читается
целиком. Английский и иврит подгружаются из `i18n/*.json`.
Язык выбирается так: `?lang=xx` → прошлый выбор → язык браузера → русский.
Иврит переключает страницу в RTL; вёрстка на логических свойствах,
поэтому зеркалится сама.

## Локальный просмотр

`fetch` к файлам по `file://` браузер запрещает, поэтому для проверки
английского и иврита нужен любой статический сервер:

```
python3 -m http.server 8000
```

и `http://localhost:8000/?lang=he`.
