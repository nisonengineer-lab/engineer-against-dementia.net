Видео

Здесь будет живая картинка с камер и записи по событиям. Смотреть их сможет только владелец системы — тот, кто отвечает за человека. Ни у нас, ни у кого-либо ещё доступа к ним нет: видео не покидает дом.

Что появится на этой странице

  • Камеры дома в реальном времени, по одной и сеткой
  • Запись по событию: минута до и минута после
  • Быстрый переход из записи журнала прямо на нужную секунду
  • Комнаты без камер остаются без камер — там работает радар
